# Mu2 all-fNL overlay figure

The revised PDF overlays the three fNL cases on shared axes instead of using separate node columns. The top row shows the 70-training-realization Gaussian mu2G curves and 30 held-out means with realization scatter; the middle row shows raw mu2 with the Gaussian baselines; the bottom row shows connected residuals and a zero reference.

This remains a diagnostic visualization at Ngrid=64 and s=40--300 Mpc/h. Raw and connected panels are not production fits because the halo four-point closure is still open.
