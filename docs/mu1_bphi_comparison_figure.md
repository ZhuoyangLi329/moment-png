# μ1 training-response b_phi comparison figure

`mu1_bphi_training_vs_universal.pdf` compares two CIC-both μ1 predictions with the same held-out N-body means: the universal mass-function `b_phi=5.467` branch and the training-response diagnostic `b_phi=3.764` branch. Both use `b1=2.7413` and `P_shot=5467.8` calibrated from fiducial training `P_h`.

The lower response from the training branch visibly reduces the LC± over-response. Its held-out Hartlap χ²/dof values are 1.96, 4.41, and 2.46 for fiducial, LC_m, and LC_p. The training-response value is explanatory only and remains blocked from production until an independent matching b_phi calibration is found.
