# Stage 2 (P_h) residual attribution

This diagnostic uses the same lattice and volume convention as the N-body comparison and reports four effects separately. At (k\le0.03\,h\,\mathrm{Mpc}^{-1}), the CIC tree model to N-body mean ratios are 0.9993 (fiducial), 0.9075 (LC−) and 1.0727 (LC+).

The fiducial large-scale (b_1) proxy changes from 2.8385 before CIC correction to 2.8599 after correction, a (Delta b_1=0.02135) mesh-transfer effect. The (P_{\rm shot}=0) versus 3603 comparison changes the fiducial (k_{\max}=0.03) (chi^2/\mathrm{dof}) from 6.78 to 1.27, but the source fits also use different (b_1), so this is retained as a coupled shot-plus-amplitude diagnostic rather than an isolated shot-noise claim.

The nonlinear residual grows with (k_{\max}), while the LC− and LC+ low-k offsets remain. The output is `DIAGNOSTIC_OPEN`; no (b_1), shot term or CIC choice is promoted to the production mean.
