# (b_phi) literature scope audit

The screening target is the frozen production selection: z=1, FoF halos with (M_h\ge10^{13}\,h^{-1}M_\odot), real-space pre-reconstruction response, and the current CIC estimator.

The Quijote-PNG bias-response analysis in JCAP 06 (2025) 053 is relevant and uses z=1 and (f_{NL}=\pm100), but its reported comparison uses Rockstar (M_{200b}), (M_{200c}), and (M_{500c}) halos above (5\times10^{13}\,h^{-1}M_\odot). It therefore fails the frozen halo finder, mass threshold, and mass-definition checks. No strict literature match was found, so the candidate is retained as rejected evidence and no numerical (b_\phi) is promoted.
