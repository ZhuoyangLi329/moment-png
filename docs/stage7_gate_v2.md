# Stage 7 gate v2

The independent Gaussian-field and iid-Poisson baselines now pass at the tested resolution grids. The Poisson contact formula agrees with the Monte Carlo connected residual at RMS pulls 1.036, 1.151, and 0.970 for Ngrid 64, 128, and 256.

The gate remains `BLOCKED`: the connected halo residual changes with resolution, and no validated term-by-term curves yet exist for halo b1/b2/bK2, bphi/bphidelta, primordial trispectrum, repeated-index, or clustered contact contributions. The baseline pass therefore does not constitute a production mu2 closure.
