# Held-out μ2 PNG response covariance audit

The frozen held-out split real070--real099 was used for a paired response audit, with response defined as `(LC_p - LC_m)/200`. The result stores realization scatter, covariance of the mean, shell pulls, raw χ²/dof, and the Hartlap-corrected statistic for raw μ2, μ2G, and connected μ2.

The Hartlap factor is `0.4827586` for 30 realizations and 14 shells. RMS pulls against zero are `24.26` (raw μ2), `26.98` (μ2G), and `4.63` (connected μ2). Restricting only for a diagnostic view to s >= 120 Mpc/h gives Hartlap-corrected χ²/dof `183.25`, `291.64`, and `3.72`, respectively.

This quantifies a measured response and does not fit an empirical response polynomial or supply an analytic halo four-point term. It therefore does not promote a production μ2 model.
