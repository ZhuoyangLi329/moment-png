# Project status at initial GitHub import

The repository is an operational measurement plus semi-analytic validation scaffold.

Passed operational layers: catalog manifest/pairing, CIC plus periodic shell moments, exact discrete Fourier window checks, Gaussian and Poisson controls, covariance diagnostics, held-out validation machinery, and PDF-only release audits.

Open scientific gates: independent b_phi and b_phi-delta inputs matched to the z=1 halo selection, complete MARISA-B halo-bias loop closure, exact consistency of CIC/mesh conventions in the forward model, and the full connected halo four-point/contact-term model for mu2.

Empirical A/k^2 templates remain diagnostics only and must not be presented as the final analytic model.
